# ResiliNet

## Descripción del proyecto

ResiliNet es una propuesta de solución digital orientada a fortalecer la comunicación y coordinación comunitaria ante situaciones de emergencia, facilitando la difusión de alertas y el acceso a información de seguridad.

## Autores

- Integrantes del Grupo 2.

## Segmentos objetivo

- Ciudadanos de comunidades expuestas a situaciones de emergencia.
- Brigadistas y equipos de respuesta comunitaria.
- Líderes y organizaciones comunitarias.

## Funcionalidades principales

- Visualización de niveles de alerta.
- Simulación de estados de riesgo.
- Notificaciones y comunicación comunitaria.
- Identificación de zonas seguras.
- Solicitud de auxilio.
- Formulario de pre-registro.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git y GitHub
